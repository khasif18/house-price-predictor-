Project Title

Feature Engineering, Model Optimization & Performance Comparison using California Housing Dataset

Objective

The objective of this project is to build and compare multiple machine learning regression models for predicting house prices using the California Housing Dataset. The project follows a complete machine learning workflow, including data exploration, preprocessing, model training, evaluation, and performance comparison.

Day 2 – Data Preprocessing
Activities Completed
Separated input features (X) and target variable (y).
Split the dataset into training and testing sets using an 80:20 ratio.
Applied StandardScaler for feature scaling.
Generated scaled training and testing datasets for model training.
Purpose

Feature scaling ensures that all numerical features are on a comparable scale, helping regression models learn more effectively and improving model performance.

Current Result

Among the three regression models evaluated, the Decision Tree Regressor achieved the best performance by producing the lowest RMSE and the highest R² Score. Based on the current evaluation, it is the most suitable model for predicting house prices on this dataset.
